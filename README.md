# Big O Lab

Python・JavaScript・C 言語・Java のコードを貼り付けて、時間計算量の目安と推定根拠を確認できる静的サイトです。貼り付けたコードの読み取りはブラウザ内で完結します。

## 使い方

1. [docs/index.html](docs/index.html) をブラウザで開きます。依存関係のインストールやビルドは不要です。
2. 言語を選び、コードを貼り付けるかサンプルを選びます。
3. 「計算量を推定」を押すと、Big O 表記、計算量の型、判断した行を表示します。

## 推定の範囲

単一の入力サイズを想定し、単純なループ、入れ子、定数倍で増減するループ、Python の基本的なソートを扱います。スカラーの基本演算と要素の比較は定数時間と仮定します。解析は代表的な構文パターンに基づくため、コード全体の正しさや停止性は保証しません。未知の関数呼び出しや解釈できないループは判定できない旨を表示します。

C 言語と Java では、波括弧で囲んだループと整数のループ変数を想定しています。C 言語では関数を 1 つ、Java ではメソッドを 1 つ貼り付けてください。Java はクラスで囲んだメソッドや配列の拡張 for 文にも対応しています。

固定の文字列を表示する Hello World のようなコードは、対応する標準出力の書き方なら O(1) と判定します。各言語の「O(1)」サンプルで試せます。
